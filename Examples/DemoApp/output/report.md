## Непонятно, что делает элемент — 3

### Подпись «Send» похожа на имя символа, а не на текст для человека

**Экран:** Каталог
**Стандарт:** EN 301 549 п. 11.5.2.5 · WCAG 4.1.2 — Имя, роль, значение доступны программно

VoiceOver произносит «Send, button» — английское слово в приложении на языке «ru». Скорее всего, подпись не задана явно и система вывела её из имени SF Symbol.

**Было:**
```swift
Button(action: send) {
    Image(systemName: "paperplane")
}
```

**Стало:**
```swift
Button(action: send) {
    Image(systemName: "paperplane")
}
.accessibilityLabel("Отправить")
```

> Подпись описывает действие на языке пользователя, а не имя символа из кода.

### Подпись «Кнопка» не описывает назначение элемента

**Экран:** Каталог
**Стандарт:** EN 301 549 п. 11.5.2.5 · WCAG 4.1.2 — Имя, роль, значение доступны программно

VoiceOver произносит: «Кнопка, button». Человек слышит роль, но не понимает, что произойдёт при нажатии.

**Было:**
```swift
.accessibilityLabel("Кнопка")
```

**Стало:**
```swift
.accessibilityLabel("<что произойдёт при нажатии>")
```

> Признак «кнопка» VoiceOver добавляет сам — дублировать его в подписи не нужно.

### В подпись попало имя ресурса: «ic_close_24»

**Экран:** Каталог
**Стандарт:** EN 301 549 п. 11.1.1.1 · WCAG 1.1.1 — Текстовая альтернатива нетекстовому содержимому

VoiceOver произносит: «ic_close_24, button». Это имя файла из проекта, а не описание для человека.

**Было:**
```swift
Image("ic_close_24")
```

**Стало:**
```swift
Image("ic_close_24")
    .accessibilityLabel("<назначение элемента>")
```

> Если картинка декоративная — уберите её из дерева целиком: .accessibilityHidden(true).

## Понятно с усилием — 1

### 3 элемента звучат одинаково: «Подробнее»

**Экран:** Каталог
**Стандарт:** EN 301 549 п. 11.5.2.5 · WCAG 4.1.2 — Имя, роль, значение доступны программно

Все они произносятся как «Подробнее, button». На слух их невозможно различить, а глазами они различаются окружением.

**Было:**
```swift
Button("Подробнее") { open(item) }
```

**Стало:**
```swift
Button("Подробнее") { open(item) }
    .accessibilityLabel("Подробнее: \(item.title)")
```

> Альтернатива без изменения подписи — объединить карточку в один элемент через .accessibilityElement(children: .combine).
